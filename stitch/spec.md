
 Role: Expert UI Designer for Academic and Scientific Workspaces.
  Objective: Create a high-fidelity, professional "Mathematical Knowledge Explorer" UI that blends
  interactive derivation with formal document reading.

  Core Visual Thesis:
   - Style: Scholarly, rigorous, and minimalist.
   - Typography: Dual-type system. Use a clean Sans-serif for navigation/controls and a premium Serif (e.g.,
     New York, Georgia) for long-form mathematical text and titles.
   - Palette: Neutral blue-gray palette. Base: #F4F6F8, Panel: #FBFCFD, Accent: #3F5F7A (Dusty Blue), Text:
     #1D2733.

  Layout Modules:
   1. The Navigation Rail: A slim, dark-themed vertical bar with high-contrast icons for "Workspace" and
      "Library".
   2. The Exploration Sidebar: A light-gray panel with a hierarchical "Session Tree" showing question-based
      branches and a "Book Outline" for structured chapters.
   3. The Derivation Workspace (Center):
       - Chat-based interface but avoid generic "bubbles". Use article-style containers with subtle shadows
         and wide rounded corners (20px).
       - Incorporate "Sigma" icons for AI identities (named after mathematicians like Gauss or Noether).
       - Block math formulas must be set in specialized "Math Surfaces"—containers with a #F6F8FB background
         and a #D9E2EC border.
   4. The Knowledge Library (Right):
       - A dedicated panel for formal reading.
       - Header includes "BookOpen", "Share", and "Print" affordances.
       - Features a "Symbol Registry" section: a grid of clean white cards where each cell contains a LaTeX
         symbol and its formal definition.

  Atmosphere:
   - Quiet motion (subtle fades, no bounces).
   - High information density but with generous vertical rhythm.
   - Focus on "Intuition, Proof, and Derivation" as the primary user tasks.

  Technical Reference: Ensure all LaTeX math symbols follow standard scholarly formatting (serif-style,
  well-spaced). The UI should feel like a bridge between a modern IDE and a classic physics textbook.
