# Phase 1 Milestone A 工程任务清单

## 1. 文档目标

本文档基于 [`Phase1_MilestoneA_implementation_plan.md`](./Phase1_MilestoneA_implementation_plan.md)，将 `Milestone A` 转换为真正的工程任务清单。

本文档的用途是：

1. 给实现阶段提供明确的任务分组
2. 明确每个任务的工程产出
3. 明确任务之间的依赖关系
4. 明确每个任务完成时应验证什么

本文档仍然不绑定具体技术栈，但已经进入工程交付视角。

## 2. 工程任务总览

Milestone A 建议拆成九组工程任务：

1. `E1：仓库基础结构与约定`
2. `E2：知识节点模型与存储协议`
3. `E3：Agent Action 与问答分流协议`
4. `E4：引用式回答协议`
5. `E5：待沉淀条目协议`
6. `E6：知识沉淀流水线`
7. `E7：最小知识可见性界面`
8. `E8：验收样例与回归用例`
9. `E9：Skill-Like 扩展约定`

建议按顺序推进，不建议并行启动过多任务。

## 11. 推荐执行顺序

建议工程推进顺序如下：

### 第一层：先冻结协议与样例基础

- [ ] E1
- [ ] E2
- [ ] E3

### 第二层：再冻结问答输出协议

- [ ] E4
- [ ] E5

### 第三层：打通知识回路

- [ ] E6

### 第四层：补用户可见性与验收

- [ ] E7
- [ ] E8
- [ ] E9

这个顺序的核心是：

`先定模型和协议，再定回答与扩展，再打通沉淀，再做展示和验收。`
